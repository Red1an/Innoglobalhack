# Правила разметки guide_v3 для хакатона

Основа — [guide_v2](guide_v2_rules.md), справочник организаторов и [уточнение по проверочной разметке](../decisions/2026-11-15_1640_codex_hackathon-label-policy.md). Ниже перечислены изменения для всех частей train и внутренних тестов.

| Случай | Решение |
| --- | --- |
| Названная услуга в поисковых фразах или хэштегах | Засчитываем. «Теги: плиточник, сантехника, электрика, покраска стен» дают 103–106. Изучаем всё описание, чтобы исключить явно отрицаемые и чужие услуги, сравнения, продажу и перечисление материалов вне списка поисковых услуг. Профиль хакатона получает текст вместе с SEO. |
| Шпаклёвка, шпатлёвка, шпаклевание | Явно названная работа даёт 106 независимо от упоминания покраски и обоев. Это относится и к явно предложенной шпаклёвке швов. «Заделка стыков ГКЛ», грунтовка и шлифовка без признаков малярной подготовки сами по себе 106 не дают. |
| Работы перечислены в ремонте под ключ | Конкретные названные работы засчитываем. «Ремонт под ключ» без списка работ не даёт 102–106. |
| Только комплекс или явный отказ от отдельных заказов | Исключаем черновики для ограниченных работ. Если ограничение относится только к одной услуге, остальные оцениваем по тексту. Минимальный чек и отказ от мелкого бытового ремонта сами по себе не ограничивают полноценные отдельные услуги. При исходной категории, отличной от 101, явное предложение комплексного ремонта может дать 101. |
| Источник упоминания | Учитываем описание. Артикул, описание завершённого объекта, инструкция, запрос клиента и чужие работы сами по себе не подтверждают услугу. |
| Пары работ и отказ | «Шпаклюем под обои, сами обои не клеим» даёт 106. «Штукатурим под будущую шпаклёвку» даёт 102. «Электрику выполняем только в комплексе, плитку кладём отдельно» даёт 103 при исходной 101. |

Исходный mcId исключаем из дополнительных меток. Для train исходная категория 101 подразумевается.
