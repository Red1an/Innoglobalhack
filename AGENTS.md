# Правила для агентов

## Лог решений

Каждый агент кратко записывает принятые решения в папку `decisions/`, чтобы потом можно было восстановить хронологию.

* Каждая сессия агента пишет в свой файл, потому что агенты работают параллельно. Имя файла: `decisions/ГГГГ-ММ-ДД_ЧЧММ_<агент>_<тема>.md`, где время означает начало сессии по Москве.
* Файл ведётся только дописыванием в конец. Существующие записи нельзя менять и удалять, в том числе в чужих файлах. Если решение отменяется, нужно добавить новую запись об отмене.
* Время указывается по Москве. Его можно получить командой `TZ=Europe/Moscow date "+%Y-%m-%d %H:%M"`.
* Запись делается сразу после решения, а не в конце сессии.

Формат записи:

```
## ГГГГ-ММ-ДД ЧЧ:ММ МСК | локальное или глобальное
Решение: что решили.
Причина: почему.
```

Глобальное решение влияет на других агентов или на весь проект, например на структуру репозитория, формат данных или метрику. Локальное решение касается только текущей задачи.
