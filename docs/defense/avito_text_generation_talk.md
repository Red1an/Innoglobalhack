## Текст выступления

Исполнитель может проверить и отредактировать текст перед публикацией.»

В 16 случаях текст должен появиться, в пяти модель должна отказаться. Считали пропуски, лишние черновики, найденные по шаблонам детали, а также время, токены и цену.»

**1:20–2:00.** «В режиме переписывания Sonnet сделал все 16 нужных черновиков и стоил около полутора тысяч рублей за тысячу запросов по тарифной оценке. ## Обрезка на 75 секунд

Оставить слайды **9 → 13 → 14 → 15**. Если нужно ужаться до 45 секунд, произнести первые две фразы, результат 15/16 и сразу показать подсветку цитаты.

«Классификатор уже выбрал услуги, дальше из одного объявления надо получить отдельный текст по каждой. GLM получает полный исходник и список категорий, возвращает заголовки, описания и цитаты. На 12 объявлениях с заранее заданными категориями она сделала 15 из 16 нужных черновиков и не создала ни одного из пяти лишних. В том же режиме локальная Qwen3 4B дала 7 из 16. У GLM медиана — семь секунд, цена — около 51 рубля за тысячу запросов. В исходнике бригады пять с лишним тысяч знаков про разные работы. В карточке электрики остались конкретные операции, материалы с чеками, бесплатный замер и оплата по этапам. Клик по цитате открывает нужное место в оригинале. Из пяти черновиков четыре прошли проверку цитат, один отклонили из-за неточного фрагмента.»

При сокращении первыми убрать полный список моделей, p95, разбивку токенов и стресс-тест. Оставить один результат с размером выборки, один пример черновика и один клик по исходной цитате.

## Проведение демо

1. На [слайде 15](../../presentation.html#slide-15) нажать «С начала», чтобы показать исходник целиком. Затем нажать «Виды работ» и «Материалы» под черновиком. Слева автоматически подсветятся фрагменты исходника. Для этого шага хватит скачанного HTML.
2. Для сквозного демо запустить `python3 avito_pipeline.py --replay --port 8767` и открыть [запись работы классификатора и генератора](http://127.0.0.1:8767/demo). Для просмотра остальных черновиков с длинного примера открыть [карточки бригады](http://127.0.0.1:8767/review?case=case-113). В карточках метки берутся из разметки.
3. Если спросят про длинный ввод, открыть [приложение 3](../../presentation.html#slide-18) или [полный исходник с цитатами по сантехнике](http://127.0.0.1:8767/review?case=case-018).

Для живых запросов запустить `--serve` со своим ключом Caila. Запись примера про электрику сохранила один вызов на пять меток, 33,15 с, 4 287 входных и 2 450 выходных токенов. Это время конкретного длинного запроса. Медиана 7,29 с относится к сравнительному прогону.

## Если спросят

- **Где системный промпт?** В [draft_generator/core.py](../../draft_generator/core.py). Системное сообщение складывается из базовых правил, правил `rewrite` и разделов справочника по выбранным категориям. Пример формулировки «Не добавляй услуги, цены, сроки, стаж, бесплатность и гарантии от себя».
- **Что означает 15/16?** Это число полученных нужных черновиков на фиксированных категориях. На четырёх отложенных объявлениях GLM дала 5/5 нужных и 0/2 ложных. Из 102 шаблонов фактов совпал 71. Содержательное качество проверяли отдельно на примерах.
- **Что именно проверяет код?** Схему JSON и буквальное совпадение цитат с исходником. Полноту черновика и корректность условий проверяет человек по подсвеченным фрагментам.
- **Какие есть локальные замеры?** Qwen3 4B Q4_K_M на M1 с 8 ГБ дала 7/16 нужных в `rewrite`, p50 32,43 с и 11,28 выходных ток./с по полному времени запроса. На Colab T4 aVibe Q8_0 дала 6/16 и 1/5 лишних. T-lite 2.1 Q8_0 дала 2/16 и 0/5 лишних, четыре запроса завершились ошибкой. В режиме сборки aVibe получила 8/16 нужных и 1/5 лишних, T-lite получила 1/16 нужных и 0/5 лишних. Медиана считается по полному времени запроса на конкретном устройстве. Замер GLM сделан через API.
- **Сколько вызовов на объявление?** В сквозном режиме один запрос классификатору и один генератору при наличии целевых меток. Замер 51,17 ₽ за 1 000 успешных запросов относится к этапу генерации на этом наборе.
