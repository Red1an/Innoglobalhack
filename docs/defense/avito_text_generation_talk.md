## Обрезка на 75 секунд

Оставить **9 → 10 → 11 → 15**. Показать кнопку «Оплата». Сказать, что в обоих шагах GLM 5.3 Flash и список всех допуслуг обрабатывается за один запрос генерации. Дать результат 15 из 16 на фиксированных категориях и закончить стоимостью полной связки.

## Живой прогон в приложении

Настроить доступ к API Caila и из корня репозитория запустить:

```sh
DRAFT_MODEL=just-ai/openrouter-proxy/z-ai/glm-5.3-flash \
  python3 avito_pipeline.py --serve --classifier glm --port 8767
```

Открыть [форму](http://127.0.0.1:8767/), выбрать исходную категорию, вставить новое объявление и нажать «Подготовить черновики». Исторические сценарии на `/demo` содержат сохранённые ответы другой конфигурации. Сохранённый пример электрики открывается прямо в HTML презентации.

## Сколько стоят метки и черновики вместе

Сквозной набор из 262 объявлений, GLM 5.3 Flash на обоих этапах. Суммарное время 340,23 с при восьми параллельных обработчиках. Медиана на вход — 8,45 с, p95 — 23,42 с.

| Этап | Вызовов | Входные токены | Выходные токены | Расход API, оценка |
| --- | ---: | ---: | ---: | ---: |
| Классификация | 262 | 1 062 306 | 37 137 | 19,28 ₽ |
| Генерация | 204 | 389 263 | 131 617 | 9,94 ₽ |
| Всего | 466 | 1 451 569 | 168 754 | 29,22 ₽ |

Формула по каждому этапу — `(входные токены × 17,2993 + выходные токены × 24,3653) / 1 000 000`. [Ставки Caila, сверенные командой с биллингом классификации](../../demo_ui/prices.json). Для генерации применены те же ставки для того же API-маршрута. Это оценка по токенам с зафиксированными ставками. Сумма сырых `usage.cost` в сквозных логах — 35,76056 в единицах поля API, валюта в логах отсутствует. Для точного списания за этот сквозной прогон нужен отчёт биллинга по тем же вызовам.

- **Входное объявление:** 29,22 ₽ / 262 ≈ 11,2 коп. В среднем примерно 5 540 входных и 644 выходных токена за оба этапа.
- **Объявление с двумя вызовами:** 204 входа, в среднем 12,2 коп. В 58 случаях хватило классификации.
- **Объявление, давшее ровно один черновик:** 74 входа, в среднем 10,1 коп. за пару вызовов.
- **Один выданный черновик в пачке:** 29,22 ₽ / 497 ≈ 5,9 коп. Расход на все входы и отклонения включён. Из 544 запрошенных черновиков проверку цитат прошли 497, хотя бы один такой черновик получили 192 объявления. В 28 строках итоговая проверка выгрузки нашла пустые черновики.
- **100 000 входов:** около 11,2 тыс. ₽ за API при таком же составе трафика, размере текстов и ставках. Хостинг, мониторинг, ручная работа, дополнительные ретраи и тарифы закупки считаются отдельно.

Замер рассчитан по локальным журналам `private_eval/runs/final/organizer-262/results.jsonl`, `run.json` и `validation.txt`. Сравнение генераторов на фиксированных категориях лежит в [сводке замеров](generation_benchmark.json). Сохранённые примеры для показа доступны в [карточках](../../private_eval/examples/draft-review).

## Коммерческие вопросы

**Что получает площадка?** Гипотеза пилота — больше опубликованных объявлений в релевантных категориях с меньшими затратами времени продавца. Проверяем на A/B-тесте по приросту публикаций и целевых контактов. Отдельно смотрим долю правок, отклонения модерации и дубли.

**Во сколько обходится дополнительная публикация?** Делим полный дополнительный расход на прирост публикаций относительно контроля. Пример: при приросте на 5 п. п. получится 11,2 коп. / 0,05 ≈ 2,24 ₽ API за дополнительную публикацию. Пять пунктов — сценарий для расчёта, эффект продукта ещё не измерялся.

**Что сильнее всего влияет на стоимость?** В прогоне на классификацию пришлось около 66% оценки API. Дальше стоимость зависит от длины входа, доли объявлений с допуслугами и объёма ответов. Один вызов генератора обслуживает сразу все найденные категории. В пилоте имеет смысл измерять себестоимость и долю потерянных услуг, прежде чем добавлять более дешёвый роутер.

**Можно ли убрать внешний API?** На ноутбуке Qwen3 4B запускалась, но дала 7 из 16 нужных черновиков на тесте генерации. Стоимость собственного сервера и качество двойной GLM при самостоятельном развёртывании предстоит замерить отдельно.

**Что считается подходящим черновиком?** Проверка цитат подтверждает связь текста с исходником на уровне фрагментов. Перед публикацией проверяются релевантность услуги, условия, цена и полнота. Бизнес-метрика — дополнительные публикации и контакты, прошедшие выбранные ограничения по качеству.
