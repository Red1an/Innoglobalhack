Для каждой найденной услуги мы готовим отдельный текст. В генератор отправляем полное объявление и сразу весь список меток. Он возвращает заголовок, описание и дословные цитаты, на которые опирался. Исполнитель может проверить и отредактировать текст перед публикацией.»

**0:30–1:00.** «Чтобы замерить генерацию отдельно, всем моделям дали одинаковые исходники и категории. Взяли 12 объявлений и 21 пару “объявление и услуга”. В 16 случаях текст должен появиться, в пяти модель должна отказаться. Сравнили два режима. В первом модель собирает объявление из фрагментов. Во втором она пишет самостоятельное описание и прикладывает точные цитаты. Считали пропуски, лишние черновики, найденные по шаблонам детали, а также время, токены и цену.»

**1:00–1:40.** «В режиме переписывания Sonnet сделал все 16 нужных черновиков и стоил около полутора тысяч рублей за тысячу запросов по тарифной оценке. Qwen3‑235B как генератор дал 12 нужных и один ложный. Для написания текста выбрали GLM. Она получает метки от любого подключённого классификатора.»

## Обрезка на 75 секунд

Оставить слайды **9 → 12 → 13**. Если нужно ужаться до 45 секунд, произнести первые две фразы, результат 15/16 и сразу показать подсветку цитаты.

«Классификатор уже выбрал услуги, дальше из одного объявления надо получить отдельный текст по каждой. GLM получает полный исходник и список категорий, возвращает заголовки, описания и цитаты. На 12 объявлениях с заранее заданными категориями она сделала 15 из 16 нужных черновиков и не создала ни одного из пяти лишних. На этом прогоне медиана — семь секунд, цена по API — около 51 рубля за тысячу успешных запросов генератора. Вот сохранённый ответ модели. В исходнике бригады пять с лишним тысяч знаков про разные работы. В карточке электрики остались конкретные операции, материалы с чеками, бесплатный замер и оплата по этапам. Клик по цитате открывает нужное место в оригинале. Из пяти черновиков четыре прошли проверку цитат, один отклонили из-за неточного фрагмента.»

При сокращении первыми убрать полный список моделей, локальные замеры, p95, разбивку токенов и стресс-тест. Оставить один результат с размером выборки, один пример черновика и один клик по исходной цитате.

## Проведение демо

1. На [слайде 13](../../presentation.html#slide-13) нажать «С начала», чтобы показать исходник целиком. Затем нажать «Виды работ» и «Материалы» под черновиком. Слева автоматически подсветятся фрагменты исходника. Для этого шага хватит скачанного HTML.
2. Для сквозного демо запустить `python3 avito_pipeline.py --replay --port 8767` и открыть [запись работы классификатора и генератора](http://127.0.0.1:8767/demo). Для просмотра остальных черновиков с длинного примера открыть [карточки бригады](http://127.0.0.1:8767/review?case=case-113). В карточках метки берутся из разметки.
3. Если спросят про длинный ввод, открыть [приложение 3](../../presentation.html#slide-16) или [полный исходник с цитатами по сантехнике](http://127.0.0.1:8767/review?case=case-018).

Для живых запросов запустить `--serve` со своим ключом Caila. Запись примера про электрику сохранила один вызов на пять меток, 33,15 с, 4 287 входных и 2 450 выходных токенов. Это время конкретного длинного запроса. Медиана 7,29 с относится к сравнительному прогону.

## Если спросят

- **Где системный промпт?** В [draft_generator/core.py](../../draft_generator/core.py). Системное сообщение складывается из базовых правил, правил `rewrite` и разделов справочника по выбранным категориям. Пример формулировки «Не добавляй услуги, цены, сроки, стаж, бесплатность и гарантии от себя».
- **Что означает 15/16?** Это число полученных нужных черновиков на фиксированных категориях. На четырёх отложенных объявлениях GLM дала 5/5 нужных и 0/2 ложных. Из 102 шаблонов фактов совпал 71. Содержательное качество проверяли отдельно на примерах.
- **Что именно проверяет код?** Схему JSON и буквальное совпадение цитат с исходником. Полноту черновика и корректность условий проверяет человек по подсвеченным фрагментам.
- **Какие есть локальные замеры?** Qwen3 4B Q4_K_M на M1 с 8 ГБ дала 7/16 нужных в `rewrite`, p50 32,43 с и 11,28 выходных ток./с по полному времени запроса. На Colab T4 A-vibe дала 6/16, T-lite — 2/16. Развёртывание выбранной GLM в собственном контуре не измеряли.
- **Сколько вызовов на объявление?** В сквозном режиме один запрос классификатору и один генератору при наличии целевых меток. Замер 51,17 ₽ за 1 000 успешных запросов относится к этапу генерации на этом наборе.

Сохранённые ответы для демонстрации и их метрики лежат в [private_eval/examples/draft-review](../../private_eval/examples/draft-review). Для сверки сравнительного прогона см. [сводку замеров](generation_benchmark.json).
